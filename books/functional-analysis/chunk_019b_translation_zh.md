# Chapter 8 Fourier 分析中的振荡积分

## §6 Application to some dispersion equations / 若干色散方程的应用

### §6.1 The Schrödinger equation / Schrödinger 方程（Theorem 6.3 收尾）

PDF 371 完成 **Theorem 6.3 / Strichartz estimate** 的证明。把时空变量写成 `(x,x_{d+1})`，其对偶变量为 `(ξ,ξ_{d+1})`，并取抛物面

`M={(ξ,ξ_{d+1}): ξ_{d+1}=-2π|ξ|²}`。

在 `M` 上取一个在 `|ξ|≤1` 区域等于 1 的光滑紧支撑测度。由于抛物面的 Gauss 曲率非零，§5 的 restriction theorem 及 Proposition 5.3 的对偶形式给出 extension operator `R*` 的 `L²(M)→L^q(R^{d+1})` 有界性。令 `F(ξ,ξ_{d+1})=f^(ξ)`，并把 `x_{d+1}` 识别为 `t`，就得到频率支撑在单位球时的 **(41)**：

`||e^{itΔ}f||_{L^q(R^{d+1})} ≤ c||f||_2`。

最后用抛物缩放 `f_δ(x)=f(δx)`、`u_δ(x,t)=u(δx,δ²t)` 把频率球任意放大，再用紧频率支撑函数在 `L²` 中的稠密性，完成全体 `f∈L²` 的 Strichartz 估计。

### §6.2 Another dispersion equation / 另一类色散方程

这里考虑一维三阶色散方程

`∂_t u = ∂_x³ u,    u(x,0)=f(x)`，

其演化算子满足

`(e^{t(d/dx)^3}f)^(ξ)=e^{t(2πiξ)^3}f^(ξ)`。

与 Schrödinger 不同，这个方程允许实值解。对 `t≠0`，演化仍可写成卷积，其核由 **Airy integral**

`Ai(u)=(1/(2π))∫_R e^{i(v³/3+uv)}dv`

给出：

`K~_t(x)=(3t)^(-1/3) Ai(-x/(3t)^(1/3))`。

原书的 **(42)** 给出 Airy 函数的有界性与 `|u|^{-1/4}` 型衰减，由其第一条直接得到

`||e^{t(d/dx)^3}f||_∞ ≤ c|t|^{-1/3}||f||_1`。

**Theorem 6.4**：若 `u=e^{t(d/dx)^3}f`，则

`||u||_{L^8(R²)} ≤ c||f||_{L²(R)}`。

证明与 Theorem 6.3 平行，把问题化为 `R²` 中三次曲线

`Γ={(ξ1,ξ2): ξ2=-4π²ξ1³}`

上的 restriction theorem。

关键是 **Lemma 6.5**。若

`I(ξ)=∫_R e^{2πi(ξ1 t+ξ2 t³)}ψ(t)dt`，

则 `I(ξ)=O(|ξ|^{-1/3})`。证明按 `|ξ2|` 是否占主导分两类：当 `|ξ2|` 较大时，把积分在 `|t|≈|ξ2|^{-1/3}` 处分开，并在外部区间用二阶导数检验；当 `|ξ1|` 占主导时直接用一阶导数检验。于是 Corollary 5.5 可取 `δ=1/3`，得到 `p=8/7,q=8`，从而证明 Theorem 6.4。

### §6.3 The non-homogeneous Schrödinger equation / 非齐次 Schrödinger 方程

现在考虑 **(43)**

`(1/i)∂_t u - Δu = F`

和零初值 **(44)** `u(x,0)=0`。形式解是 Duhamel 算子 **(45)**：

`S(F)(x,t)=i∫_0^t e^{i(t-s)Δ}F(·,s)ds`。

**Proposition 6.6** 说明：当 `F` 是 `R^d×R` 上的 `C∞` 紧支撑函数时，`S(F)` 是 `C∞`，并满足方程与初值。

核心估计是 **(46)**：

`||S(F)||_{L^q(R^d×R)} ≤ c||F||_{L^p(R^d×R)}`，

其中 `q=(2d+4)/d`，尺度不变性强制 `p=(2d+4)/(d+4)`，即 `q` 的对偶指数。

**Theorem 6.7** 证明 (46)。书中先把 `S` 换成

`S+(F)=i∫_{-∞}^t e^{i(t-s)Δ}F(·,s)ds`

再加入 `e^{-ε(t-s)}` 得到 `S_ε`，目标是先证明与 `ε` 无关的 **(47)**。

随后把 `S_ε` 嵌入解析族 `T_z`，其卷积核是 **(48)**：

`K_z(x,t)=γ(z)e^{-|x|²/(4it)}(4πit)^(-d/2)e^{-εt}t_+^z`。

其时空 Fourier multiplier 可显式计算。解析族两条边界分别是：

- **(49)** `Re(z)=-1` 时 `L²→L²`，常数与 `ε` 无关；
- **(50)** `Re(z)=d/2` 时 `L¹→L∞`，常数同样与 `ε` 无关。

Proposition 4.4 插值得到 `T_0:L^p→L^q`。再通过时空 Fourier 变换验证 **(51)** `T_0=S_ε`。最后令 `ε→0`，先对正时间再对负时间应用估计，就得到 (46)，完成 Theorem 6.7。

**Proposition 6.8** 给出 Duhamel 解更强的时间正则性：若 `F∈L^p(R^d×R)`，可在零测集上重新定义 `S(F)`，使每个固定 `t` 都有 `S(F)(·,t)∈L²(R^d)`，并且 `t↦S(F)(·,t)` 在 `L²` 范数中连续。

基础估计是 **(52)**：

`||∫_α^β e^{-isΔ}F(·,s)ds||_2 ≤ c||F||_p`，

它本质上是 Theorem 6.3 的对偶。由此得到 **(53)**：

`sup_t ||S(F)(·,t)||_2 ≤ c||F||_p`。

再用光滑紧支撑函数逼近 `F`，把时间连续性传到一般 `L^p` 强迫项。

### §6.4 A critical non-linear dispersion equation / 临界非线性色散方程

原书接着研究 **(54)**：

`(1/i)∂_t u - Δu = σ|u|^{λ-1}u,    u(x,0)=f(x)`。

它具有两项重要守恒量：

- mass：`∫|u|²dx`；
- energy：`∫(1/2|∇u|² - σ/(λ+1)|u|^{λ+1})dx`。

现在取初值 `f∈L²(R^d)`。若要求方程在缩放

`u(x,t) ↦ δ^a u(δx,δ²t)`

下保持形式，同时保持初值的 `L²` 范数不变，就必须有 `a=d/2`，因此临界指数为

`λ=1+4/d`。

此时还恰好有 `q=λp`，其中 `p,q` 正是 Theorem 6.7 与 Theorem 6.3 中的那一对指数。

原书把 **strong solution** 定义为：`u` 属于相应时空 `L^q`，在分布意义满足方程；每个 `t` 时 `u(·,t)∈L²`，并且时间到 `L²` 的映射连续且满足初值。这个定义也可以限制在 `|t|<a` 的有限时间区间。

**Theorem 6.9**：

1. 存在 `ε>0`，若 `||f||_2<ε`，则 (54) 有全局 strong solution；
2. 对任意 `f∈L²`，存在依赖于 `f` 的 `a>0`，使得在 `|t|<a` 上存在 strong solution。

证明采用不动点法。令 `u_0=e^{itΔ}f`，问题化为 **(55)**：

`u = σS(|u|^{λ-1}u)+u_0`。

对小数据全局情形，取

`B={u∈L^q(R^d×R): ||u||_q≤δ}`

并定义

`M(u)=σS(|u|^{λ-1}u)+u_0`。

PDF 380 已证明第一步的主要估计：由 Theorem 6.7 与 `q=λp`，

`||S(|u|^{λ-1}u)||_q ≤ c||u||_q^λ`，

所以只要 `δ` 足够小、再让 `||f||_2<ε` 足够小，就有 `M(B)⊂B`。此外利用复数上的点态估计

`||u|^{λ-1}u-|v|^{λ-1}v| ≤ c_λ|u-v|(|u|+|v|)^{λ-1}`

和 Hölder 不等式，可把 `||M(u)-M(v)||_q` 控制为

`c'_λ ||u-v||_q |||u|+|v|||_q^{λ-1}`。

取 `δ` 足够小即可让压缩常数不超过 `1/2`。证明在 PDF 380 末尾尚未结束，下一批继续完成固定点收敛、强解性质以及任意数据的局部存在。

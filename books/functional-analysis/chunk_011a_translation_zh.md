## 1 Bernoulli 试验 / 1.1 抛硬币

做 N 次公平抛硬币。把正面记作 `0`、反面记作 `1`，样本空间是

`Z_2^N={x=(x_1,...,x_N): x_j∈{0,1}}`。

共有 `2^N` 个结果点，均匀概率测度对每个点赋质量

`m({x})=2^{-N}`, 因而 `m(Z_2^N)=1`。

### 坐标事件与独立性

令 `E_n={x:x_n=0}` 表示第 n 次为正面，则 `m(E_n)=1/2`。不同坐标满足

`m(E_n∩E_m)=m(E_n)m(E_m), n≠m`，

这正是“第 n 次与第 m 次抛掷独立”的测度表达。

### 收益函数 / Rademacher 坐标函数

定义 `r_n(x)=+1`（第 n 次正面），`r_n(x)=-1`（第 n 次反面）。总收益为

`S_N(x)=Σ_{n=1}^N r_n(x)`。

若 `S_N=k`，则正面数 `N_1=(N+k)/2`、反面数 `N_2=(N-k)/2`，因此 k 必须与 N 同奇偶。对应概率是书中的式 (1)：

`m({x:S_N(x)=k}) = 2^{-N} N! / [((N+k)/2)!((N-k)/2)!]`。

对允许的相邻 k 值，

`m(S_N=k+2)/m(S_N=k)=(N-k)/(N+k+2)`，

所以分布从左端逐渐增大，在中心附近达到最大，再对称减小。N 为偶数时最大值在 `k=0`；Stirling 公式给出中心概率的尺度

`m(S_N=0)≈sqrt(2/π) N^{-1/2}`。

这为后面 `N→∞` 的极限定理提供最初的离散模型。

# Chapter 8 Fourier 分析中的振荡积分

## §4 Return to the averaging operator / 回到平均算子（收尾）

PDF 361 首先完成 **Lemma 4.6**。在 `s=0` 时，前面的解析延拓公式化为对 `F(u)e^{-2πiuρ}` 的导数积分，由此得到 `I_0(ρ)=N!F(0)`。回到 Proposition 4.5，把 `u=x_d-φ(x')` 代入核 `K_s` 的 Fourier 变换，得到公式 **(28)** 所对应的表示：

`K_s^(ξ)=e^{s²} I_s(ξ_d)`，

其中 `I_s` 中的 `F(u)` 是关于 `x'` 的振荡积分。Theorem 3.1 给出 `F` 及其 `u` 导数的曲率型衰减，再和 Lemma 4.6 的 `|ξ_d|^{-Re(s)}` 衰减结合，得到 Proposition 4.5 所需的一致 Fourier 估计。

随后把 `T_s(f)=f*K_s` 放入 Proposition 4.4 的解析插值框架。条带左端 `Re(s)=-(d-1)/2` 给出 `L²→L²`，右端 `Re(s)=1` 给出 `L¹→L∞`；而 `s=0` 时 `T_0=N!A`。由

`0=(1-θ)(-(d-1)/2)+θ·1`

得到 `θ=(d-1)/(d+1)`，从而

`1/p=d/(d+1),  1/q=1/(d+1)`，

即 `p=(d+1)/d, q=d+1`。这完成 **Theorem 4.1** 的第二部分。

## §5 Restriction theorems / 限制定理

### §5.1 Radial functions / 径向函数

对一般 `L^p` 函数，Fourier 变换只作为几乎处处定义的 `L^q` 函数存在，因此“限制到低维曲面”并非自动有意义。径向函数先给出一个积极信号。

**Proposition 5.1**：若 `f∈L^p(R^d)` 径向，则当

`1≤p<2d/(d+1)`

时，`f^` 在 `ξ≠0` 处连续。证明使用径向 Fourier 变换的 Bessel 表示 **(29)**

`F(ρ)=2πρ^{-d/2+1}∫_0^∞ J_{d/2-1}(2πρr)f_0(r)r^{d/2}dr`

和 `J_ν(u)=O(u^{-1/2})`，把问题降为控制 **(30)**

`∫_1^∞ |f_0(r)| r^{d/2-1/2}dr`。

Hölder 不等式恰好给出阈值 `p<2d/(d+1)`，而书中指出这个范围不能再扩大。

### §5.2 The problem / 限制问题

固定超曲面 `M⊂R^d` 与光滑紧支撑曲面测度 `dμ=ψdσ`。核心问题是：是否存在 `q` 使 **(31)**

`(∫_M |f^(ξ)|^q dμ(ξ))^{1/q} ≤ c||f||_{L^p(R^d)}`

成立？若成立，就称 `M` 具有 `(L^p,L^q)` restriction property。

本书给出三点背景：

1. 非平凡限制结果必须依赖一定曲率；
2. 若 Gauss 曲率处处非零，预期范围为 `1≤p<2d/(d+1)` 且 `q≤((d-1)/(d+1))p′`；
3. `d=2` 时这一猜想正确；`d≥3` 的完整范围在本书语境下仍未知，但 `q=2` 的重要部分可以证明。

### §5.3 The theorem / 限制定理主体

**Theorem 5.2**：若 `supp dμ` 上 Gauss 曲率非零，则 **(31)** 在

`q=2,  p=(2d+2)/(d+3)`

时成立。

定义 restriction operator

`R(f)=f^|_M`

和伴随 extension operator

`R*(F)(x)=∫_M e^{2πiξ·x}F(ξ)dμ(ξ)`。

二者满足对偶恒等式 **(32)**：

`(R(f),F)_M=(f,R*(F))_{R^d}`。

组合算子满足 **(33)**：

`R*R(f)=f*k,  k(x)=dμ^(-x)`。

**Proposition 5.3** 是经典 `TT*` 机制：以下三件事等价：

- `R:L^p→L²(M)`；
- `R*:L²(M)→L^{p′}`；
- `R*R:L^p→L^{p′}`。

因此只需证明 `R*R` 的卷积估计。书中再次使用 §4 的解析核族：令 `S_s(f)=f*k_s`，其中 `k_s(x)=K_s^(-x)`。在 `Re(s)=1` 得到 `L²→L²`，在 `Re(s)=-(d-1)/2` 得到 `L¹→L∞`，而 `s=0` 恰好给出 `N!R*R`。解析插值得到

`1/p=(d+3)/(2d+2),  1/q=1/p′`，

从而 Theorem 5.2 得证。

**Corollary 5.4** 把临界 `q=2` 情形与平凡 `p=1,q=∞` 再做一次 Riesz 插值，得到

`1≤p≤(2d+2)/(d+3),  q≤((d-1)/(d+1))p′`。

**Corollary 5.5** 把结论直接写成 Fourier 衰减的函数：若所有局部曲面测度满足

`|dμ^(ξ)|=O(|ξ|^{-δ})`，

则 `q=2` 时可取

`p=(2δ+2)/(δ+2)`。

特别地，若至少有 `m` 个非零主曲率，由 §3 的衰减可得 `p=(2m+4)/(m+4)`。

## §6 Application to some dispersion equations / 若干色散方程的应用

### §6.1 The Schrödinger equation / Schrödinger 方程

本节先研究线性色散方程 **(34)**

`(1/i)∂_t u = Δu`

配初值 **(35)** `u(x,0)=f(x)`。形式上定义 Schrödinger propagator **(36)**：

`(e^{itΔ}f)^(ξ)=e^{-it4π²|ξ|²}f^(ξ)`。

### Proposition 6.1：Schwartz 空间层面

对每个 `t`：

1. `e^{itΔ}:S→S`；
2. `u=e^{itΔ}f` 是 `(x,t)` 的 `C∞` 函数并满足方程与初值；
3. 当 `t≠0`，`e^{itΔ}f=f*K_t`，其中 `K_t(x)=(4πit)^{-d/2}e^{-|x|²/(4it)}`；
4. 色散估计 `||e^{itΔ}f||_∞≤(4π|t|)^{-d/2}||f||_1`。

关键 Fourier 恒等式是 **(37)**

`K_t^(ξ)=e^{-it4π²|ξ|²}`。

书中从实 Gaussian Fourier 恒等式出发，对复参数 `s=σ+it` 解析延拓，再令 `σ→0`，在 tempered distributions 意义下得到 (37)。

### Proposition 6.2：L² 层面

`e^{itΔ}` 在 `L²(R^d)` 上是 unitary；`t↦e^{itΔ}f` 在 `L²` 范数中连续；并且对一般 `f∈L²`，`u=e^{itΔ}f` 在分布意义满足 Schrödinger 方程。其测试函数形式是 **(38)**。

把 `L¹→L∞` 和 `L²→L²` 插值得到 **(39)**：

`||e^{itΔ}f||_q ≤ c_p |t|^{-d(1/p-1/2)}||f||_p`,

其中 `1/q+1/p=1, 1≤p≤2`。

接着考虑时空整体衰减 **(40)**：

`||u||_{L^q(R^d×R)}≤c||f||_2`。

尺度变换 `f_δ(x)=f(δx)`、`u_δ(x,t)=u(δx,δ²t)` 强制唯一可能的指数为

`q=(2d+4)/d`。

**Theorem 6.3（Strichartz estimate）** 正是断言这个临界指数的 (40) 成立。PDF 370 已给出定理陈述，并指出它与 §5 的 restriction theorem 在 `R^{d+1}` 上出现的对偶指数完全一致；**证明从 PDF 371 继续。**

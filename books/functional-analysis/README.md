# Functional Analysis 中文结构化数据 v0.1

本目录是 Book Course OS 对 Stein & Shakarchi《Functional Analysis》的第一轮结构化结果。

## 已完成

- 442 页 PDF 的 page label / 纸质页码映射
- 20 页一组的 23 个分卷清单
- 全书目录的英中双语结构化
- 第 001 分卷（PDF 1-20）的内容类型拆分
- 前言、第四卷序言、第一章导言的中文学习层翻译
- 第一章初始知识节点

## 关键规则

- 原文和中文译文分层保存，不覆盖原文。
- PDF 页码和纸质印刷页码分别保存。
- 正文中目前 `printed_page = pdf_page - 19`，但程序仍以 `page_map.csv` 为事实源。
- 图片/公式保留原始 PDF；后续公式会逐条结构化为 LaTeX。
- “预习 / 学习 / 复习 / 刷题”由用户主动选择，结构数据只提供内容，不设置流程锁。

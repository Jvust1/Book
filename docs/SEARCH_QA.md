# 教材搜索与提问

## 目标

每本教材结构化后都必须支持“搜索”和“提问”，且回答能够跳回教材具体来源位置。

## 搜索顺序

1. 定理/命题/公式编号精确匹配
2. 中文名称、英文名称、常用别名匹配
3. 结构化知识节点语义检索
4. 小节与中文学习层检索
5. 原始 PDF 兜底检索

## 搜索结果

每条结果至少返回：

- `book_id`
- `book_version_id`
- `object_id`
- 中文/英文标题
- PDF 物理页
- 纸质印刷页
- `content_anchor_id/source_anchor`
- 对应章节、小节
- 可直接跳转的教材位置

## 提问规则

提问默认作用域为“当前教材”。

回答优先依据：

1. 已结构化定义/定理/公式/证明/例题
2. 中文学习层
3. 已绑定课堂记录（后续）
4. 原始 PDF 兜底

如果问题涉及尚未完成结构化的页面，必须明确标注“该内容尚未完成结构化”，可以暂时引用原始 PDF 搜索结果，但不能伪装成已经验证过的结构化结论。

每个回答都要返回教材来源锚点，支持：

`答案 → 教材原处 → 一键返回问题`

## 中英双语检索

数学、金融和英语教材都需要保存中英双语关键词。例如：

- Hahn-Banach theorem / Hahn-Banach 定理
- dual operator / 对偶算子
- partition of unity / 单位分解

用户输入中文或英文都应命中同一知识节点。

## 实现建议

第一阶段采用混合检索：

- 编号/标题/术语的关键词索引
- alias 索引
- 结构化节点 embedding
- page/section 过滤器

后续可增加：

- 按章/节限定搜索
- 只搜公式/定理/题目
- 搜老师课堂内容
- 搜错题和个人笔记
- 多教材联合提问

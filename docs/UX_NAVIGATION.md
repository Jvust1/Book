# Book 交互与导航规范

## 1. 总体原则

- 学习行为优先，聊天不是主入口。
- 预习 / 学习 / 复习 / 刷题四个入口并列，用户自由选择。
- 所有“跳转到来源”的行为必须支持快速返回。
- 返回后恢复原页面状态，避免重新寻找位置。
- 教材、课堂、考点、题目之间形成可双向导航的学习网络。

## 2. 课程首页

建议展示：

- 当前课程
- 主教材与辅助教材数量
- 最近课堂
- 即将到来的考试 / 作业
- 今日复习建议
- 最近学习位置

避免把 AI 聊天框放在首屏中心。

## 3. 章节页

```text
第 4 章 资本成本
├── 4.1 ...
├── 4.2 WACC
├── 4.3 ...
└── Chapter Hub
```

Chapter Hub 包含：

- 章节总结
- 核心知识点
- 本章公式
- 考点
- 思维导图
- 本章测试

## 4. 小节页

顶部固定：

**预习｜学习｜复习｜刷题**

四个按钮：

- 并列
- 不锁定
- 不要求先后顺序
- 各自显示状态

示例：

```text
4.2 WACC

[预习 已完成] [学习 70%] [复习 2次] [刷题 18/30]
```

## 5. 预习页

结构建议：

1. 本节要解决什么问题
2. 前置知识
3. 核心概念
4. 核心公式预览
5. 教材关键图
6. 易卡点
7. 带着问题听课
8. 快速检测

目标是短，不把预习做成完整学习页。

## 6. 学习页

按知识点卡片组织：

```text
知识点标题
├── 主教材
├── 辅助教材
├── 英文原版
├── 老师讲解
└── 我的笔记
```

每个知识点内部：

- 教材核心内容
- 图 / 表
- 公式
- 示例
- 易错点
- 课堂补充
- 来源定位

## 7. 复习页

用户可以直接选择：

- 1 分钟
- 5 分钟
- 完整复习
- 闪卡
- 错题重做

复习内容围绕统一知识点生成，不局限于某一本教材。

## 8. 刷题页

支持：

- 按章节
- 按知识点
- 按考点
- 按难度
- 按来源
- 只刷错题

每道题做完后展示：

- 对应知识点
- 错误类型
- 教材原文入口
- 返回当前题目

## 9. 考点页

每个考点不只是文字描述，而是一个导航节点。

示例：

```text
WACC 的计算与适用条件
优先级：S

教材对应内容
- 定义 → 主教材 P216
- 公式 → P217
- 使用条件 → P218
- 例题 → P220

课堂
- 第 7 次课 01:06:42
- 第 9 次课 00:31:18

相关题目
- 教材题 4-12
- 错题 3 道
```

## 10. 考点 → 教材快速跳转

点击某个来源时：

1. 保存当前考点页状态
2. 打开教材定位视图
3. 自动跳到目标页
4. 自动滚动到具体内容锚点
5. 高亮目标段落 / 公式 / 图 / 例题
6. 顶部或底部持续显示“返回考点”

## 11. 快速返回

返回时恢复：

- 考点页滚动位置
- 已展开卡片
- 当前筛选器
- 当前教材来源选择
- 当前考点

用户不应被送回页面顶部。

## 12. 导航栈

示例：

```text
考点页
→ 教材公式
→ 教材例题
→ 返回教材公式
→ 返回考点页
```

或：

```text
考点页
→ 课堂录音 01:06:42
→ 返回考点页
```

导航状态由客户端 `NavigationState` 管理。

## 13. 前后考点

考前复习模式支持：

**上一个考点｜下一个考点**

形成连续路径：

```text
考点 1 → 查看教材 → 返回 → 下一考点
```

## 14. 教材页视图

教材页同时支持两种定位显示：

- 纸质教材页码
- PDF 内部页码

界面优先显示纸质页码，程序内部保留 PDF 页索引。

可显示：

```text
教材 P87 · PDF P102
```

## 15. 多教材切换

同一知识点存在多个来源时：

```text
[主教材] [辅助教材] [英文教材] [课堂]
```

切换来源不改变当前知识点上下文。

## 16. 课堂录音页

录音状态下优先保持极简：

- 实时字幕
- ⭐ 重点
- 🎓 考试
- 📝 作业
- ❓ 没听懂
- 💡 拓展

不要求用户在课堂上频繁输入文字。

## 17. 实时字幕

课堂中先保证跟得上老师。

显示：

- 当前实时字幕
- 最近若干句
- 专业术语纠错提示
- 低置信度提示

课后再生成完整精修稿。

## 18. 原始稿 / 精修稿切换

课堂详情页：

```text
[原始逐字稿] [AI精修稿]
```

任何精修段落都支持点击“听原话”，跳到原始录音时间戳。

## 19. 课堂事件卡

课后自动生成：

- 重点
- 考试
- 作业
- 截止时间
- 教材拓展
- 课程规则

每张卡显示：

- 提取内容
- 置信度
- 来源时间戳
- 确认 / 修正

## 20. 考试中心

建议结构：

```text
考试中心
├── 成绩构成
├── 期中
├── 期末
├── 已确认考点
├── 高概率考点
├── 不考内容
└── 我的掌握度
```

## 21. 思维导图

思维导图节点必须可点击。

点击知识点后进入知识点详情，并可继续跳到：

- 教材
- 课堂
- 题目
- 考点
- 笔记

## 22. 搜索

全课程搜索结果按来源分组：

```text
WACC
├── 教材 3 处
├── 课堂 8 处
├── 考点 1 个
├── 题目 17 道
├── 笔记 4 条
└── 错题 3 道
```

## 23. 关键体验验收

以下体验必须做到顺畅：

1. 打开任意节，可直接点四个模块中的任意一个。
2. 从考点一键定位教材具体内容。
3. 从教材一键返回原考点且位置不丢失。
4. 从考点一键回听老师对应原话。
5. 多教材切换不丢失当前知识点上下文。
6. 教材更新后历史课堂和笔记仍能继续定位。

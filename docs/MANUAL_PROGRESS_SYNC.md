# 手动同步学习进度

Book 0.1.4 的 Android 和 Windows 应用使用同一种 JSON 学习进度包，无需登录、云盘或 API。

## 操作

1. 在进度较新的设备打开“同步”。
2. 点击“导出学习进度”，在系统窗口中保存 JSON 文件。
3. 用聊天工具、数据线或局域网把文件传到另一台设备。
4. 在另一台设备打开“同步”，点击“导入学习进度”并选择该文件。
5. 如果两台设备都产生了新进度，依次双向导出、导入一次，再从任一端导出合并后的文件回传即可。

导入以每个“小节 + 学习模式”的 `updated_at` 为准，较新的记录覆盖较旧记录；重复导入同一文件不会重复增加记录。同步包不包含录音、教材正文、问答记录或账号凭据。

只有从 Book 应用中导出的 `book_study_sync_v1` 文件可导入。应用会拒绝未知课程、小节、教材版本、无时区时间和状态不一致的记录。建议保留最近一次导出的文件，确认两端进度后再自行删除旧文件。

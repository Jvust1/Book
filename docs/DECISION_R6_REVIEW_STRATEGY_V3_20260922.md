# 决策记录：r6 审校策略 v3 — 结构化优先，PDF 定点核对

日期：2026-09-22。

## 决定

对**已经存在较完整结构化数据**的教材，不再把“整本逐页重新打开 PDF 机械比对”作为默认复审流程。

默认顺序改为：

1. 全量审核现有 Markdown / JSONL / LaTeX / 图像索引和来源锚点；
2. 检查章节顺序、编号、定义/定理/证明引用、公式变量与条件、跨页连续关系、例题/习题完整性、图表引用、页码映射、疑似摘要化/漏段/OCR 异常；
3. 只有拿不准或发现高风险疑点时，才打开对应 PDF 页及必要的前后页；
4. 如果问题是“数学上是否正确”，优先做内部推导、自洽性检查、反例、符号或有范围的数值验证；必要时再查外部权威资料；
5. source / correction / derived 继续严格分层。

## PDF 仍然负责什么

需要确认“原书到底印了什么”时，扫描页面视觉内容仍是最高来源证据。PDF 文本层只辅助，模型不得凭猜测替代来源。

但这条来源权威规则**不再被解释成必须对已有结构化数据做整书逐页重扫**。

## 首次录入仍不同

一本新扫描教材第一次建立结构化数据时，仍要连续处理来源页，保证不跳页、不漏正文/公式/图表/例题/习题。

本策略只优化**已有结构化数据的后续复审**。

## 完成度分开统计

- `structured_review_complete`：结构化全量审核完成；
- `targeted_pdf_issues_resolved`：被触发的 PDF 疑点已解决或明确 OPEN；
- `full_page_visual_verification`：只有真的逐页视觉核过才能标 true；
- `mathematical_review_status`：数学正确性独立统计。

因此，后续不能把“没逐页重看 PDF”直接叫作“数据未完成”，也不能把“结构检查完成”冒充“全书逐页视觉验收完成”。

## 当前 r6

Batch5 数据本身不因本决策改变；当前 App 源码也不需要仅为治理文本重新打包。历史 v2 与已有页级台账继续保留，v3 从现在起作为默认审校规则。

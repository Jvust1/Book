# 教材全书结构化完成后的通篇质量检查

每本教材只有通过本质量门，才允许标记为 `STRUCTURED_COMPLETE`。

## 1. 页码与覆盖

- PDF 物理页全部进入 `page_map`。
- 检查纸质页码跳号、重复、罗马数字/正文混淆。
- 每一个正文 PDF 页至少属于一个 section/content unit。
- 检查空洞页、重复页、插页与扫描异常。

## 2. 章/节边界

- 目录中的章、节、小节全部存在。
- 起止页与实际页面标题一致。
- 跨 chunk 的节、定理、证明不能被错误截断。
- `continues_in / continued_from` 必须成对闭合。

## 3. 数学对象

- 定义/定理/命题/引理/推论编号连续且无重复。
- 公式编号没有缺失或错挂。
- 定理与证明正确绑定。
- 交叉引用指向真实对象。
- 重要符号前后一致。

## 4. 图表与例题

- 有教学意义的图像保留原图锚点。
- 图号、标题、页码匹配。
- 表格同时保留原图与结构化数据（适用时）。
- 例题、练习、问题没有误识别成正文。

## 5. 中文学习层

- 专业术语全书一致。
- 人名/定理名译名统一。
- 变量、上下标、积分域不因翻译改变。
- 重点复核否定、条件、量词、存在/唯一、充分/必要。
- 对解析异常位置回看原 PDF 页面。

## 6. 搜索与提问

- 每个核心对象至少一个稳定 `source_anchor`。
- 中英文名称、编号、常用别名均可检索。
- 搜索结果可跳到 PDF 页/纸质页/具体对象。
- 提问回答必须返回来源锚点。
- 未结构化或证据不足时不能伪装成教材结论。

## 7. 自动异常扫描

至少扫描：

- 无 section 归属页面
- 重复 object_id
- 重复 theorem number
- 起止页倒置
- 锚点落在 section 范围之外
- unresolved `continues_in`
- 空译文节点
- 长度异常节点
- 公式疑似乱码节点
- 图号跳跃

最终生成 `BOOK_AUDIT_REPORT.md`，所有问题分为：

- PASS
- WARN：需要人工复核
- FAIL：必须修正

只有 `FAIL = 0` 后，该教材才能标记为结构化完成。

解出增量ZIP根目录的 `recover_r6_delta.py`，运行：

```sh
python recover_r6_delta.py --base /path/r6-source.zip --delta /path/Book-TwoCourses-r6-batch2-Delta.zip --out /path/new-r6-batch2-candidate
```

输出目录必须不存在。恢复器先校验基线ZIP和所有变化文件的前后哈希，再建立新候选目录，拒绝覆盖已有工作区。原ZIP、原工作区和旧版笔记都不改。增量ZIP内 `delta-manifest.json` 列明每个新增/变化文件的大小及前后SHA；恢复后应重新执行测试和完整性检查。

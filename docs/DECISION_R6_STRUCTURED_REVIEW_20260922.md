# 决策记录：结构化数据优先审校

日期：2026-09-22。用户在上一轮明确同意 Strategy v2；本轮要求一次多完成一些。本记录是执行依据与边界，不是新增授权或数学验收。

## 为什么切换

PDF 的印刷形式不是数学正确性的充分证据。此前逐页检查也证明“已有页锚/记录”不等于逐字完整：泛函曾有一段被摘要化的证明。两种问题应分开：来源是否忠实，用原件定点解决；公式、前提和推理是否成立，用定义、推导、反例、符号或有范围的数值验证解决。

过去的516页台账继续作为历史证据保存，不抹去也不补造已核对页数。全书逐页 PDF 比对不再是主线。本次没有新增 PDF 页比对活动，没有用结构扫描条目数冒充校读页数。

## 本轮执行

对全部9,355条来源记录做机器可复现的结构、来源哈希、引用、公式索引和四视图检查；对13个修正对象与7项疑点决定作定点数学分析。两者分别统计，不能把全量结构扫描称为全量数学证明审校。

每个修正绑定原记录身份、原始内容、理由与证据。11项HIGH记录可以优先显示，2项MEDIUM候选只能显示校注，不能替换正文。HIGH是证据等级而不是可靠性概率，也不是独立审阅通过。原文、修正版、AI推导相互分层。

泛函第二至第五章80题新增完整参考推导草稿，原第一章30题保留。题干、推导、适用约定分开。来源题号和哈希与答案绑定，避免错配。参考推导全部继续标为非官方、待独立校核。

## 不做的事

不使用模型信心作为证明；数值抽查不冒充恒等式全域证明；对歧义根号、参数域、归一化或术语不强行统一。不把“易证/从略”启发式线索当成错误。不把课程包更新冒称为Android已发布。
